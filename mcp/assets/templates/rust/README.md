# 🔤 {{TITLE}}

Un contador de palabras en Rust: de contar a la tabla de frecuencias.

```console
$ cargo run -q --example demo -- "el gato y el perro"
5 palabras
  2 el
  1 gato
  1 perro
  1 y
```

## Qué vas a aprender

- A partir un texto en palabras sin que te engañen los espacios.
- A contar con un `HashMap` y su API de `entry`.

## Antes de arrancar

- Rust y saber escribir una función.
- ~20 min en total.
